For Claude Code

Open README.md first. tokens.css drops into your global stylesheet; tokens.json is the same data for build tools (Tailwind, Style Dictionary, etc.). The two React components in react/ are the canonical mark implementations — use them in product. The static SVGs in assets/ are for email, OG images, print, and any non-React surface.
